# 中国AI现场部署服务（FDE）行业白皮书

> 从 Demo 到生产的最后一公里，谁在填补 AI 落地的鸿沟

作者：张研ᴷᴱᴺ｜焕燃科技 & 研之有理 CEO  
版本：v0.1.0 开源 Markdown 版  
定位：中国 AI 现场部署服务行业研究与交付方法论

## 内容简介

本白皮书讨论企业 AI 从演示走向生产时的关键断层：系统对接、权限安全、流程改造、合规审计、组织协同和商业模式。全书采用九章加附录的结构，覆盖行业背景、企业需求、人才市场、市场规模、商业化路径、风险趋势、标杆案例、安全隐私、组织能力建设与职业发展。

**适合阅读**：企业 CEO、CIO、数字化负责人、AI 产品与交付负责人、FDE、售前与解决方案工程师、企业服务创业者。
