街道南端（出生点身后约 23 m）新增第二块可玩区域，可玩边界从 z 52 扩到 **z 84**：

| 空间 | 尺寸 / 坐标 | 说明 |
| --- | --- | --- |
| **南院车场** | 34×26 m（x ±17，z 56–82） | 从街道穿过「DEPOT」门架进入；沥青场地 + 混凝土前坪，集装箱、厢式货车、两辆废弃车、垃圾箱、沙袋、油桶火堆、灯柱、管道堆 |
| **车库** | 10×12 m（x 5–15，z 66–78） | 北向 6.4 m 卷帘门进入（门朝街道，从门口就能看进去）；内有卡车、工作台、货箱，一盏暖光灯泡 |
| **车库屋顶** | 3.72 m | 从车库西侧外部斜坡走上去（无台阶），屋顶有天窗、空调箱、麻袋；北侧矮墙留出与斜坡齐平的缺口 |
| **围栏 / 大门** | z 82 | 南侧铁栅门（关闭、带门柱与灯），外圈 2.6 m 矮墙把地平线收住 |

玩法接入：

- **敌人出生点 +7**（南院四角与大门），可以从玩家背后压上来，不再只从北侧来敌；屋顶 +1 个狙击点（`ROOF_SPAWNS`）。
- **掩体点 +8**、**防守/撤离目标点 +2 组**：`yard`（南院中心 r8）与 `depot`（车库 r3.6/3.2），随波次轮换。
- **区域名**：`南院车场 / SOUTH YARD`、`车库 / DEPOT`、`车库屋顶 / DEPOT ROOF`。
- **场景过渡**：街道与院区之间加了门架 + 抬起的栏杆 + 招牌，南侧建筑端墙补了窗洞 / 卷帘门 / 空调 / 落水管 / 污渍，避免“走到地图边缘看到一堵空白墙”。

### 南院地标与可破坏掩体（Sprint G）

- **燃料岛**：南院中部（x 1.0, z 71.6）4.6×2.6 m 水泥岛 + 5.4 m 雨棚 + 两台加油机 + 防撞柱 + 油污，既是第二个地标也是可绕可蹲的掩体（新增 2 个掩体点）。
- **水塔**：院区西侧（x -6.6, z 62.6）11 m 高水塔——四根钢腿 + 交叉拉杆 + 6.7 m 检修平台 + 2.9 m 锈蚀水罐 + 锥顶 + 爬梯/落水管；从街道大门口就能看到罐体，是最容易记忆的锚点（`REGIONS` 仍归属南院车场）。
- **可破坏掩体 +4**：南院木箱、沙袋堆、金属路障、木托盘（`south-crate` / `south-sacks` / `south-barricade` / `south-pallets`，hp 55–130），打碎走原有 `hitDestructible()`（碎片 + 碰撞体移除 + 战地统计里的“摧毁掩体”）。

### 敌人侧翼与区域切换（Sprint G）

- **出生分布**：survival 波次约 **1/3 的敌人从侧后出生**（`pickSpawnPoint()`，朝向点积 < -0.15、距离 16–52 m），波次 ≥2 才启用；剩余仍取远端出生点，避免正面挤成一队。
- **AI 侧翼**：枪兵/突击兵推进到 20 m 外时侧向展开系数 0.55 → 0.95，不再对着玩家画直线。
- **区域切换**：交战中的枪兵每 6.5–12 s 触发一次 `reposition`——优先选“相对玩家方位变化 >63°、距玩家 7–26 m”的掩体点，没有可用掩体就沿自己的 `flankSide` 绕到侧面；走到后 1.7–3 s 内重新交战。掩体只在真实受击时触发（原有逻辑不变）。

## 🕸️ AI 导航与搜索（Sprint H）

敌人不再只会朝玩家直线推进：

- **导航网格**（`src/systems/navgrid.js`）：0.8 m 均匀栅格（73×183）、按 0.32 m 代理半径把 2D 碰撞体膨胀成障碍，A*（8 邻接、禁止贴角穿越）+ 视线拉直（string pull）。只服务地面单位（`baseY ≤ 0.5`），屋顶狙击手仍走自己的边界钳制。
- **路径跟随**：`advance / search / reposition` 三种状态每 0.85–1.4 s 或在目标移动 >2.2 m 时重算；A* 前先做一次 `lineWalkable`，直线可达就不跑 A*（多数情况零开销）。
- **搜索状态**：失去视线后记住最后可见位置，追过去搜 3.6 s；7 s 没再看见就转入推进。破门/绕后时敌人会追你进房间，而不是原地发呆。
- **侧翼**：推进到 20 m 外时侧向展开系数 0.95；交战中每 6.5–12 s 触发一次 `reposition`，优先换到“相对玩家方位变化 >63°”的掩体点。
- **出生分布**：survival 波次约 1/3 从侧后出生（`pickSpawnPoint()`），其余仍取远端。
- **越界修复**：敌人地面钳制放宽到 `x ±28 / z -63..83`，南院出生的敌人不再被拉回 z=50。

### 代价项 / 动态重烘焙 / 分层（Sprint I）

- **移动代价**：贴墙的格子 ×0.88（AI 更愿意沿掩体走）；你开火时 `nav.markThreat()` 会在落点和弹道中点标记 2.2–2.6 m 的“压制区”（+0.8–1.3/格，最高 3.2，1.1/s 衰减），A* 会绕开你正在架的枪线。实测：在 `(0,30)` 标记 8 m/10 强度后，`(0,20)→(0,40)` 的路径从直穿变为绕到 x≈2。
- **动态重烘焙**：打碎可破坏掩体时，`nav.refreshRegion()` 只重算该物体外 0.5 m 方框内的格子（重新光栅化 + 重算掩体折扣），AI 立刻可以走进被打碎的箱子位置。
- **屋顶↔地面分层**：网格分 3 层（地面 / 屋顶 3.20 / 屋顶 3.72），坡道顶端与屋顶之间用**自动检测的门户**相连——只有“地面高度 ≈ 屋顶高度、且不在屋顶投影下”的格子才会生成门户，避免从天花板打洞上楼。敌人沿坡道爬升时 `followHeight` 跟踪所在路径层，脚底高度按 4.5 m/s 上台阶、8 m/s 下落；离地 ≥2 m 时跳过 2D 碰撞（否则会被屋顶下方的墙卡住）。
- **实测**：`findPath(0,60,0 → 10,72,3.72)` 返回 `…(4,66)→(4,71)→(5,72,roof)→(10,72,roof)`；枪兵从 `(0,60)` 上坡 4 s 内站上 3.72 m 屋顶并在屋顶交战，玩家下到地面后它能原路走下来；普通波次里地面/屋顶单位高度分别为 0 / 3.2 / 3.7，无 NaN。

### 命中与遮挡（Sprint J）

- **子弹不再穿墙**：合并后的静态网格是 FrontSide，从室内向外开枪时射线打的是背面，会被背面剔除。Sprint N 改成**同几何的隐形 DoubleSide 射线副本**（`bullet-surfaces`，共享几何、不产生 draw call），再加 three-mesh-bvh 加速：不再用 AABB 盒子近似，所以窗洞、矮墙、栏杆上方的子弹不会被一张 10 m 高的隐形墙吃掉。
- **碰撞体带高度**：`addCollider*` 增加 `top`（`meshBox` 自动用 `y + h/2`），玩家移动、敌人移动、敌人视线都会跳过“低于脚底/低于视线”的几何——站在甲板上不会被甲板下的墙卡住，也能从矮掩体上方看到/打到目标。
- **网格越界修正**：栅格原来用 `floor/ceil` 标格，会把每个碰撞体**多标一格**（0.8 m），导致南院被道具切出大片假死区；改成“只标记中心落在膨胀矩形内的格子”后，`(0,76)`、`(-9,71)`、`(12,71)`、`(16,70)` 等点位全部恢复可达。
- **压制区裁剪与开销**：威胁点现在只落在射线实际命中点（墙会截断），衰减只遍历被标记过的格子，不再全图扫 1.3 万格。
- **穿堂捷径**：公寓到后院那 0.65 m 深的门洞用一条手工 `navLink`（`level.navLinks`）连接两侧格子，AI 也会走这条捷径了。

### 射击手感与命中判定（Sprint N）

- **射线预算**：合并后的世界是 ~1.2M 三角形，暴力 raycast 单发要 **8.9 ms**，霰弹枪 8 弹丸 ≈ **72 ms**——开一枪掉四帧。现在给每个合并 buffer 建 BVH（three-mesh-bvh），实测单发 **0.03 ms**、霰弹 **0.24 ms**（BVH 构建 60 ms，只在载入时做一次）。
- **后坐力图案**：前 8 发固定爬升（0.26°→0.40°）+ 交替水平漂移，累积上限 0.66°，ADS ×0.6；`controller.js` 的弹簧保留，所以抬枪/回正是连续的，不会瞬移。
- **准星与弹道同源**：HUD 准星半径由真实散布角按当前 FOV 换算成像素，M4 腰射 6.9 px、霰弹 25 px；移动散布从 2.4× 降到 1.6×。
- **霰弹弹丸分布**：8 颗弹丸用黄金角低差异序列铺开（第 1 颗保持准心），不再纯随机导致偶尔全空。
- **实测（24.6 m、静止腰射、15 发连射）**：修复前 **5/15**，修复后 **15/15**；镜头爬升 1.34° → 0.34°。

## 🔊 音频修复（Sprint R.1）

**为什么之前听不到配音**：MiniMax 的 TTS 接口返回的 `data.audio` 是 **hex 字符串**，不是 base64。第一版按 base64 解码，落盘的 32 个 `.mp3` 全是坏文件（`ffprobe` 报 Header missing），浏览器 `<audio>` 直接 `MEDIA_ERR_SRC_NOT_SUPPORTED`。所以「有文件、有 200、`play()` 返回 true」都是假象。

修复：

- 全部 32 条台词按 **hex** 重新解码生成；`ffprobe` 校验 32/32 可播放（32 kHz 单声道 MP3，2.5 MB）。
- `audio` 增加 `resume()`；`startGame` 入口统一 `init → resume → setMasterVolume`，并用一次性的 `pointerdown / keydown` 解锁 WebAudio（键盘开始游戏也能出声）。
- 修掉 `initAudioAmbience()` 把主音量硬编码成 0.58、覆盖玩家设置的问题。
- 语音音量跟随主音量（`voice.setVolume(master)`）。

**自检**：控制台执行 `__game.audio.debug`，应看到 `{ state: 'running', master: 0.58 }`；战役 OP01 开场约 1 秒后应听到 VEGA。仍然静音的话先看标签页是否被静音/系统音量，再看 `ctx.state` 是否 `suspended`。

## 🎮 局域网合作（Season 3）

**2–8 人合作生存**，同一张地图、同一套波次/AI/道具。房主权威模拟敌人和波次，客户端本地移动、发送射击；服务端只做 WebSocket 中继，不做权威模拟。

```bash
# 房主机器：同时开网页和 LAN 中继（两个终端）
npm run dev:lan              # 网页 0.0.0.0:5173，局域网可访问
npm run lan                  # 中继 0.0.0.0:8790
# 其他人用浏览器打开 http://<房主IP>:5173 ，点 LAN CO-OP，
# 填 ws://<房主IP>:8790 + 同一房间码，JOIN；房主按 START。
# 也支持 http://<房主IP>:5173/?lan=ws://<房主IP>:8790
```

> 线上 HTTPS 版（`https://dod.goodpoint.top`）已通过 nginx 把 `/lan` 反代到本机 8790，客户端会自动用 `wss://dod.goodpoint.top/lan`，不需要再填 `ws://`。如果要让**房主自己的机器**做中继，仍需用 **HTTP 局域网页面**（`http://<房主IP>:5173`）连 `ws://<房主IP>:8790`，否则 HTTPS 页面会被 mixed content 拦截。Linux 防火墙需放行 5173/8790 TCP。

### 榜单是异步快照，不要求服务端与游戏同时在线

- 打开菜单或切换模式时，先画本地镜像，再后台拉取；**45 秒内复用缓存**，点来源徽章可强制刷新。
- 分页：每页 20 条，滚到底自动请求下一页，最多 100 条；到底显示「已到底 · 共 N 名」，加载中显示「加载中…」。已加载的页会合并进本地镜像（按 runId 去重、最多 100 条），断网也能翻。
- 徽章含义：`ONLINE` = 本次拉取成功；`CACHE` = 显示的是上次成功快照；`LOCAL` = 没有远端数据。
- 脚注始终标出数据新鲜度：`同步 21:30` 或 `未同步`；离线提交会显示 `待补交 N`（outbox 最多 20 条，联网后自动补交）。
- 榜单是**历史最好成绩**，不是在线玩家列表；服务端离线不影响游戏，也不会把已有榜单清空。

### 完整排行榜弹层（FULL BOARD）

终端页脚右侧是 `更多 · FULL BOARD`，点开是一个盖在菜单之上的模态层（`z-index:86`，菜单压暗虚化）：TOP 100、每页 50 条，滚到底或点「加载更多」翻页，自己那行琥珀高亮，底部显示 `已显示 N / 总数` 与来源徽章。`ESC`、点遮罩、右上角 × 都能关闭，关闭后焦点回到「更多」。

- 打开时先用终端已缓存的页立即出内容，再异步刷新第 0 页；离线只翻缓存时按钮会如实显示「离线 · 仅缓存」，不假装已到底。
- 弹层打开时菜单被置为 `inert`，键盘不会 Tab 到背后的 START；如果你用键盘在 START 上按了 Enter，开局前会先把弹层关掉。

### 呼号（用户名）怎么存

- 首次进入自动生成 `OPERATOR-XXX`（取本机随机 `client id` 的后 3 位，共 12 字符上限）。
- 保存在 `localStorage['dod.callsign.v1']`；点 CALLSIGN 改名即时写入。提交成绩时随 run 一起发给服务端，服务端按 1–12 位清洗后写进榜单条目。
- **没有账号、密码或登录**：同一个浏览器 + 同一份 localStorage 就是同一个身份；换设备、清缓存、无痕窗口都会得到新的 client id 与呼号。
- 改名只影响之后的提交；已入榜的旧记录不会回溯改名。结算页改名会用同一 `runId` 幂等重提，只更新这一条。
- 只收集随机 client id 与呼号，不采集邮箱、手机号或设备指纹。

## 🧠 AI v2：感知 / 小队指挥 / 掩体（Sprint X）

旧版 AI 是「每 0.2 秒二值视线 → 各自选目标 → 直走或绕墙」：没有视锥、没有反应时间、没有协同；多个敌人会抢同一个掩体、挤成一团；北楼/东码头还因为旧的敌人边界 `-28..28 / -63..83` 被夹到一条墙线上。

现在拆成四层：

| 模块 | 做什么 |
| --- | --- |
| `src/systems/ai/perception.js` | 视锥 + 距离 + 视线（按敌人错峰节流）、awareness 0–1、听觉（玩家枪声 / 队友枪声 / 冲刺脚步）、压制值、首次接触计时 |
| `src/systems/ai/director.js` | 每 0.3 s 分配角色：`assault / flank / suppress / hold`；按难度限制同屏名额；左右侧翼分配；掩体预约；给失去视野的士兵“带误差的旧情报”，而不是透视 |
| `src/systems/ai/cover.js` | 只有“蹲下能挡住玩家视线”的点才算掩体；候选来自关卡掩体点 + 附近碰撞体的四个墙面；到点后 hide / peek 循环 |
| `src/systems/ai/steering.js` | 单位分离（1.9 m）、不穿玩家身体、A* 路径拉直、接近目标减速 |

难度档 D1–D5 不再只是命中/伤害乘数：`tuning.js` 里每档有自己的反应时间、视锥、awareness 速度、同屏突击/侧翼/压制名额、掩体倾向、“情报刷新间隔”、**跟枪提前量（lead）**、**首次射击延迟（firstShot）** 与 **重伤后后撤（regroup）**。D1 基本是单点推进，D5 是 2 路突击 + 2 路包抄 + 2 路压制。

每个 3 人以上的小队**至少保留 1 名 hold**（base of fire）：没有火力线的队伍不是小队，只是一群各自乱晃的人。掩体预约的键名由 `coverKey()` 统一生成，写入方（director）与查询方（cover）不可能再对不上——旧版本两套格式不同，预约从未生效过，两个兵会挤进同一个箱子。

难度轴**不跟波次序号走，而跟任务号走**：战役里每个任务原本都从 wave 1 开始，于是 14 关全程只有 D1–D2，连手雷都不会出现。现在 `G.diffSeed` 把任务号接到难度轴上（OP01→D1 … OP14→D5），波号仍然管节拍、刷兵与检查点。

**掩体判定是 3D 的**：掩体点必须真的挡住“玩家眼位 → 蹲姿士兵头部”这条 3D 视线（`systems/ai/geom.js` 与 AI 自己的视线用同一个函数），不再用 2D 平面遮挡近似——否则会出现“士兵蹲在掩体后双方都看不见对方”的僵持。玩家蹲下（眼位 1.05 m）现在真的会让子弹打不中，敌人的视线与曳光也瞄准胸口而不是脚底。

射击模型也改了：进入视野后要经过 `reactionDelay` 才允许开第一枪；命中率随持续瞄准 `aimSettle` 从约 55% 收敛到 100%；跑动开火、被压制都会掉精度。掩体里只有 `peek` 阶段能开火，躲藏阶段不能。

另外修了两个会直接毁掉“像人”的问题：

- 敌人世界边界改用 `level.bounds`，北楼/东码头不再被压到 `z=-63 / x=28` 的死线。
- 高台上的 rusher 自动改成 rifleman，不会出现霰弹兵卡在平台边缘送死。

单次采样的方差很大（出生点、掩体、玩家位置都会影响），这组数只能说明“承伤没有系统性失控”，不是精确平衡。

### 敌方战术道具与呼应（Sprint X.1）

玩家本来就有手雷（`G`，每局 2 发，升级/拾取 +1，7 m 爆炸）——缺的是**敌方会用**。现在按 D3+ 逐档解锁：

- **破片手雷**：你静止在掩体后约 3 s 才扔；6 m 伤害衰减（基础 60），被墙挡住再 ×0.25；目标 5 m 内有队友就不扔。
- **闪光弹**：你卡角度、队伍需要推进时；白屏 + 耳鸣 + 抖动，强度按距离和“是否正看着它”计算（背对明显减伤）。
- **烟幕**：至少 2 名敌人有视线、需要换位时；烟里 **AI 视线会被切断**，不是只挡玩家的画面。
- **破门**：你贴在关闭的破门后蹲守时，对面士兵叠加 2.5 s 后踹门（字幕 + 低频撞击 + 尘），并重新烘焙 A*。

玩家自己的破片手雷除了造成伤害，还是一枚**压制弹**：爆炸点 7.5 m 内的敌人会被压制（掉精度、找掩体、停止推进），远处的人只听到声音去查看。手雷因此是“清一条路”的工具，而不是告诉所有人你在哪的信标。

解锁与冷却：D1/D2 不扔；D3 只有破片（22–30 s）；D4 破片 20–28 s、闪光 34–44 s；D5 破片 16–22 s、闪光 28–36 s、烟幕 40–50 s。投掷者优先是压制/固守位，不是正在冲脸的突击位。

公平性约束：投掷前有 **喊话 VO + 字幕 + HUD 类型/方向箭头 + 闪灯与滴答**；**同屏最多 1 枚道具在空中**（旧版是“1 枚杀伤 + 1 枚战术”两个独立通道，闪白与手雷可以同时在空中，再叠上破门和开火就是一个无解连招）；破门触发时道具投掷会被挂起 3 s。破片爆炸是噪声事件，会惊动整队。

“静止才扔”的判定用的是**真实速度（m/s）**：旧代码把归一化的 0–1 速度当成 m/s 比较，阈值恒真，于是手雷/闪光对正在乱窜的玩家照扔。现在玩家持续冲刺时 `campT` 会被清零，`__game.aiStats().equipment.campT` 可以直接观察。

“不能炸到自己人”的规则同样被修正过：旧规则是**落点 5 m 内有任何队友就不扔**，而小队的本职就是贴在玩家身边，于是这枚手雷**一帧都没能扔出去**（实测 16 s 内 139 次否决、0 次投掷）。现在守卫半径按**爆炸伤害**取 3 m，并且尝试频率降到每 0.4 s 一次，`equipment.stats().frag` / `.denied` 可以直接看到投掷是否真的发生。

烟幕是**双向**的：它切断 AI 的视线，也吃掉双方的子弹（玩家的射击路径与 `Enemy.shoot` 都查 `perception.smokeBlocks`）。只挡 AI 不挡玩家的话，烟幕就是一个白送的进攻窗口。

**语音呼应**：`public/audio/voice/enemy/` 里有 10 条敌方喊话 MP3（发现目标 / 手雷 ×2 / 闪光 / 烟雾 / 破门 / 包抄 / 压制 / 有人倒下），总计 160 KB。它们是用 macOS 中文男声 TTS（Reed / Rocko / Eddy）降调 + 电台带通 + 压缩生成的**占位 VO**，不是真人录音；WebAudio 解码后按距离/声像播放，文件缺失时自动回落到程序化电台杂音。要换真人 VO 只需覆盖同名文件，代码不用改。

### 单人公平性校准（Sprint X.2）

玩家是一个人，敌人是整队——这是本轮重点。用“普通玩家 bot”（约 1.2° 瞄准误差、150 ms 重新索敌、点射、换弹、小范围横移）在 D3/D4/D5 各跑 24–30 s：

| 场景 | 调整前承伤（最低血量） | 调整后承伤（最低血量） |
| --- | --- | --- |
| D4 / wave 8 | 57–93（7–43） | 2–18（84–98） |
| D5 / wave 13 | 86–93（12–25） | 13–25（75–87） |

调整项：

- **同时开火人数**：D3/D4/D5 一律最多 2 人（原来 3/4/5）。这条对“一个人被五把枪集火”的改善最大。
- **命中/伤害**：D3 0.82/0.82，D4 0.94/0.94，D5 0.96/0.95（原来 0.85–1.08 / 0.85–1.10）。
- **D5 突击名额** 3→2，保留双翼包抄和压制。
- **护甲吸收** 60%→75%，脱战回血延迟 4.2 s→3.2 s。
- **道具**：解锁整体后移一档、冷却拉长、破片 95→60 伤害/7.5→6 m、掩体减伤 0.32→0.25；闪光峰值限制 0.7 且衰减更快；投掷者优先支援位。

bot 数据方差很大（出生点/掩体/是否被包抄），它只能证明“不再出现五枪同开和道具连击秒人”，不是精确难度曲线；真人体感仍需实机校准。

### 单人公平性复审（2026-10-23）

上一节的所有实测都是在 `maxFiring = 2` 下采的，但一次系统整合提交（`6e7831d`）把 D4/D5 的 `maxFiring` 悄悄改回了 **3**——代码跑的是比校准基准热 50% 的队伍，而文档、实测数据、承诺全都还写着 2。本轮把这类漂移一次性修掉，并补了回归测试。

### AI v3：可读性 · 公平性 · 归因（Sprint X.3）

这一轮不是加行为，是**把已有的机制接上，并修掉三处会直接毁掉公平性的错误**。

**公平性修复**

- **单位错配（根因）**：`controller.state.speed` 是 0–1 的归一值，AI 侧却按 m/s 使用。于是移动既不让你更难被发现，也不让你更难被打中；手雷的“静止 3 s 才扔”阈值恒真；`playerFastT` 恒假，导致射击里的“晚闪避公平复核”是死代码。现在 controller 额外导出 `state.speedMs`（真实 m/s），AI 全部改读它。
- **透视级泄漏**：awareness 可以被弹着点/被遮挡的枪声抬高，却**不产生任何 belief**，于是士兵进入 `advance` 后目标链末端 fallback 到玩家的**实时坐标**。现在任何抬 awareness 的路径都必须同时给出一个方向（弹着点、枪声位置），末端 fallback 改成“玩家所在区域 + 误差”，永远不会是实时坐标。
- **烟幕单向**：烟幕只挡 AI 视线，不挡玩家视线与弹道 —— 那是一个纯玩家收益的白送窗口。现在子弹双向穿过烟幕都会被吃掉。

**可读性修复**

- **角色可见**：assault / flank / suppress / hold 有了姿态区分（压制半蹲点射、侧翼站姿快跑、突击前压、固守蹲射），侧翼兵跑弧线时**不看你**（头转向行进方向），一眼能读出“这是在绕后”。
- **敌人瞄你的胸口**：以前视线与曳光都瞄脚底（共享玩家位置带的是地面高度），蹲下毫无意义。现在 LOS 用玩家**眼位**（站 1.68 / 蹲 1.05），曳光落在胸口，蹲下真的会让子弹打不中。
- **掩体 3D 化**：掩体有效性从 2D 平面遮挡改成与 AI 视线**同一个 3D 函数**（`systems/ai/geom.js`），不再出现“双方都看不见对方的僵持”；并按“站姿能藏 / 只有蹲姿能藏”分两档选点。

**小队协同修复**

- 每个 3 人以上小队至少留 1 名 hold；侧翼分配改为**相对玩家朝向**（原来用世界 X 轴，转身体对侧翼无效）；侧翼弧线扩到 100–170°（原来实际只有 80–92°，永远只是横向平移），且会校验可达性、不可达时换边重规划。

**包抄锚点（AI v3 定案）**

三件事同时成立，才是"包抄"：

1. **锚点是士兵自己的信念**：`lastSeen`（他亲眼看到你的位置）或 `investigate`（他听到的枪声/弹着点，或小队的区域电台报告，±12–20 m）。**没有信念就没有包抄资格**——你没找到人，就没法绕到他背后。旧代码在这里兜底用了"玩家实时位置所在区域的质心"，等于给每个士兵发了一份免费区域雷达，还把弧线落点甩到离玩家最远 60 m 的地方。
2. **弧线的参照系是主攻组，不是侧翼兵自己**：从"信念→士兵"量出来的是**侧向平移**（落点就在你旁边擦过去）；从"信念→主攻组重心"量出来的是**真正的绕后**——主攻组从你看着的方向压上来，侧翼兵从它的反面兜到你的背后来。扇区取主攻组方位角的 130–180°。
3. **警觉但没有信念的士兵仍然能拿到电台报告**：搜索超时会把 `lastSeen` 清掉，而旧逻辑跳过"已警觉"的士兵，于是他从此既没有信念、也不能包抄，小队白白少一个人。

实测（wave 8 / D4，headless，6 局）：包抄组与主攻组的方位差平均 **-0.38**（负值=在主攻组的反面），最干净的一局是 **-1.16**，包抄兵**全部（173/173）落在玩家朝向的背后**；修复前是 **+0.98、0/211 全在正面**。
- 掩体预约键名统一（见上）。
- 士气改按**真实死亡数**计算（原来数的是“目击到死亡的士兵数”，一人死两人看见就当两人死）。
- 移动向量统一归一化：侧翼兵原本实际速度是配置值的 1.27 倍。

**死亡归因**

`__game.aiStats()` 新增 `lastDamage` 与 `deaths`，`G.deathLog` 记录每次死亡时“是哪个兵种、什么角色、多远、是不是道具”。`tools/fairness.mjs` 输出 `attribution` 表（按兵种 / 角色 / 距离分桶 / 弹药类型），所以“这一波我为什么死”终于有答案，而不是靠猜。

```bash
node tools/fairness.mjs 8 30     # 末尾多出 attribution 表
node tools/ai-profile-test.mjs   # 新增：hold 保底 / flank 弧段 / 预约键名 / 无实时坐标回退
node tools/enemy-los-test.mjs    # 新增：蹲下/站姿的 3D 视线判定（同一堵箱子，只挡蹲姿）
```

**行为探针**（需要先起 dev server）：`tools/ai-audit-probe.mjs` 把一次遭遇拆成**接近段**与**接敌段**分别测量——包抄是否绕到背后要在接近段读，承伤、掩体、道具要在接敌段读。固定时间窗量的是"这波有没有刷到你"，方差不小（实测平均距离在 10 m 和 70 m 之间跳），所以探针会先等到接敌再开始计数。

```bash
npm run dev &                                  # 另开一个终端
node tools/ai-audit-probe.mjs http://127.0.0.1:5173/ 8 14
# POSTURES=crouch AUTO=0   只跑一种姿态 / 关掉玩家自动开火
```

**还没做的**：难度档仍然是“同一套状态机的倍率”，D1–D5 在战术形态上的差异还很小；玩家侧没有闪光/烟幕（只有破片手雷），所以“闪光致盲 AI”这一条没有实现——玩家目前唯一的道具反馈是手雷的压制效果。

### 波次收敛：刷兵距离带 + closeout 推进（2026-10-23）

红队评审把“波次不会来”列为 P0。根因不是单个 bug，而是**没有任何一条代码路径负责“让敌人靠近玩家”**：

- 刷兵的距离门控算的是**区域质心**（`spawn.js` 的 10.8–88 m），落到具体点位时零过滤；`spawnReachesPlayer()` 对屋顶点直接放行。街区有 81 个刷兵点，其中 **43 个在 90 m 以外**，只有 17 个在 45 m 内——一波兵完全可能刷在 130 m 外，那儿超出了每一个兵种的交战距离（rifleman 48 m）和感知上限（55 m）。
- 目标派生全部围绕**区域**转：`investigate`（区域质心 ± 12–20 m 误差）一旦设置就永久压过玩家位置，误差不随时间收敛；`flank` 路点也由区域质心派生；`advance` 走到目标的**角色站位距离**就停下（8–26 m）并开始横向平移。
- 情报时钟是 4–10 s 一跳，士兵在“情报未到”的窗口里没有任何移动理由：`hunter` profile 的 `patrol` 是 `null`，未警觉时直接进 `idle`——**站桩**。

三处改法：

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 刷兵点位 | 门控算区域质心，点位零过滤；屋顶点无条件放行 | **距离带作用在点位上**：优先 20–46 m，硬上限 80 m；越界的点退回同区域内更近的点，再不行就环形刷在玩家周围 |
| 选区 | 只看区域质心距离与方位 | 区域仍决定**从哪个方向来**，但一个“能刷出理想距离”的区域优先入选；点区内按距离选点，不再随机 |
| 收敛 | 无。目标到点即站桩，flank 弧线无超时 | **closeout 推进**：3 s 无视线接触且距离 > 22 m 的士兵直接压上，目标带**随距离收缩的误差**（4–16 m），每 2.5 s 重取一次；同时压上的人数上限 4（否则整队一起 A* 会把帧率打穿，也会让波次失去压迫节奏） |
| 屋顶单位 | 屋顶狙击手在 60 m 外站桩，占掉大量采样 | 屋顶点也受距离上限约束；屋顶单位不参与 closeout（它下不来），保留为狙击位 |
| 侧翼 | 弧线走不完就一直走 | 弧线 **14 s 超时**自动放弃 |

closeout 的公平性边界：误差有 4 m 下限、2.5 s 才刷新一次，且**只在“看不见且距离 > 22 m”时**触发——它读的是“队伍向枪声围过去”，不是实时坐标。屋顶、掩体后、Boss 不参与。

`tools/spawn-test.mjs` 新增 4 条断言（近区优先、点位落在交战带、按距离选点、远区返回空计划让调用方回退），`npm test` 里跑。

**怎么验证**（`tools/ai-probe.mjs` 现在默认**不挪玩家**——他留在游戏给他选的战区出生点，战区矩形与玩家位置一致。以前探针默认把玩家瞬移到 `(0,20)`，而战区矩形还停在随机选中的另一个战区，波次因此刷在别的战区、离玩家 72–137 m，那样的「0 伤害」是**测量假象**。要复现那个跨战区场景，显式传 `PX`/`PZ`）：

```bash
node tools/ai-probe.mjs 8 24             # 自然出生（真实场景）
PX=0 PZ=20 node tools/ai-probe.mjs 8 24   # 跨战区（仅作对照，会刷出假象）
```

## ✨ 技术栈与特性

- **渲染**：Three.js r169，WebGL2，PBR + IBL（PMREM 程序化天空）、ACES Filmic 色调映射；画质档 MSAA 0/2/2/4、像素比 1/1/1.25/2；半分辨率 SSAO 接触阴影（高/超高，贴花/天空/玻璃/积水不参与）；**动态分辨率**按帧时间在 0.72–1.0× 之间自动缩放（HUD 是 DOM，不受影响）。
- **后期**：UnrealBloom → ACES/sRGB → 自定义终级 Pass（对比/分离色调/去饱和、暗角、色差、胶片颗粒、USM 锐化、屏幕空间体积光、镜头光晕/横向光条、冲刺径向模糊、受伤/低血量/命中闪屏）。
- **天空**：解析太阳 + 多层 FBM 云 + 地平线尘霾；同一着色器生成 PMREM 环境贴图，PBR 材质获得一致 IBL。
- **材质**：全部 Canvas 程序化生成（混凝土/沥青/灰泥/砖/立面窗格/卷帘门/金属/锈/沙袋/帆布/木材/遮阳篷/招牌/涂鸦/污渍/纸张/杂草/棕榈叶…），并派生法线/粗糙度贴图；世界空间 UV 投影保证纹理密度一致。
- **关卡**：街区「AL-MAZRAH CROSSING」+ 可进入的后院与室内——低角度逆光、沿街建筑、窗洞进深、阳台/空调/消防梯/电缆/商铺、破车、沙袋、路障、瓦砾、积水、火焰桶；**后院**（世界边界 x±30）带 7×8m 市场棚屋（第三处 CQB，双入口）、**屋顶闭环路线**（坡道 → 3.2m 甲板 → 猫道 → 跳回后院）；**可破坏掩体**（木箱/沙袋堆/路障，打碎出碎片）；**南院车场**（Sprint F）在街道南端新增 34×26 m 开放院区 + 10×12 m 可进入车库 + 3.72 m 可行走屋顶（外部斜坡），集装箱/货柜车/废弃车/沙袋/灯柱做掩体，南侧用围栏大门与外圈矮墙收边。
- **武器**：三个槽位 —— M4A1（30/180，均衡）、MK18（25/125，36 伤害 / 850 rpm / 后坐 1.35，近战爆发）、M870（6/40，8 弹丸 × 22 伤害，泵动 0.8 s，逐发压弹，**4 m 内满伤、12 m 衰减到约 60%、20 m 触底 42%**）。数字键 1/2/3 选槽、`Q` 切回上一把；换枪有 **0.5 s 收枪→换枪→抬枪过渡**（期间不能开火/换弹），换枪会打断换弹进度；HUD 右下角三槽显示实时弹药并高亮当前枪，M870 在第 3 波前显示 `LOCKED`。
- **M870 模型**：独立程序化枪体 —— 长枪管 + 管状弹仓 + 枪口箍、木托/木护木、滑动泵（开火时前后泵动 0.34 s）、珠形准星；与 M4 族分开建模，换枪时整枪切换（不再只是换材质）。
- **LOADOUT**：菜单新增 `LOADOUT · 起始主武器`（M4A1 / MK18），选择存 `dod.settings.v1.primary`，开局直接拿选中的步枪；M870 在每局第 3 波解锁。
- **补给按武器类型**：空投/弹药箱给当前武器类型的弹药（霰弹 +8 发；步枪 +60 发并给另一把步枪补一半）。
- 瞄具为中空框 + 红点分划（仅步枪；霰弹枪无光学，靠珠形准星）；呼吸、行走摆动、冲刺收枪、ADS、后坐弹簧、换弹（弹匣掉落/上推/拉机柄）、检视；克制冷色 rim 光。武器在独立场景渲染，永不穿墙。
- **敌人**：分层战术装具士兵、双段腿/手臂、行走/奔跑/瞄准/蹲伏/受击/**ragdoll 倒地**；AI v2 具备**视锥 + awareness + 听觉**、反应时间、`assault / flank / suppress / hold` 小队角色、掩体验证与探头射击、单位分离、A* 路径拉直、被压制后找掩体；**Wave 9 起出现屋顶狙击手**（激光提示、锁定掩体后站位；与 D4/VETERAN 同步登场，不再在 D3 中期空降）。
- **阴影**：太阳阴影相机跟随玩家，但目标点按**光照空间 texel 网格**吸附（`snapShadowFocus`）——按世界 XZ 吸附时，斜射光下网格会随脚步滑动，窗户/栏杆的影子就会闪；改成光空间后，4.3 cm texel 下静止几何的影子保持稳定。视锥从 ±52 m 收到 ±44 m（texel 密度 +18%）。
- **射线**：three-mesh-bvh 加速（`src/core/bvh.js`），静态世界单发 raycast 0.03 ms；子弹与可见几何使用同一批三角形，不再有 AABB 近似。
- **LOD**：24 m 外的士兵隐藏小网格（弹匣/绑带/眼睛等），26 m 外不再投射阴影——实测 6 名远处敌人从 **777 draw calls 降到 336**（-57%）。
- **特效**：GPU 火花/浮尘、实例化曳光/弹孔/血渍、枪口焰三层、爆炸火球/烟柱/冲击波/碎片、大气雾壳。
- **音频**：Web Audio 全合成（分层枪声、换弹 foley、脚步、弹着、跳弹、爆炸、心跳、环境风/远处交火、闪光耳鸣、烟雾罐嘶声、10 条敌方占位 VO（TTS 降调+电台处理，缺失时合成兜底）），程序化卷积混响。
- **UI**：CoD 风格 HUD（罗盘、动态准星、命中/爆头、击杀播报、弹药刻度、护甲/血量、受击方向、**手雷类型/方向警示**、**闪光白屏**、**敌方喊话字幕**、波次/目标、连杀计数、UAV 倒计时、拾取提示）、程序化主菜单（logo 与人物立绘均为生成资产、底部 RANKING/DAILY 作战终端与呼号编辑）、**战前教学简报**（按模式给目标/威胁/提示）、**结算页**（个人数据 + 排行榜 + 今日挑战 + 呼号）、部署/暂停/阵亡界面。
- **数据与联网**：本局统计（击杀/爆头/命中率/无伤波次/可破坏物）→ 生涯档案与每日挑战存 `localStorage`；排行榜客户端 `src/net/leaderboard.js` 走同源 `/api`，带超时、离线队列（outbox）与本地镜像，服务端 `server/leaderboard.mjs` 为零依赖 Node 服务（ticket/HMAC + 数值一致性校验 + 每 IP 限流 + 单 JSON 原子落盘）。**它不是反作弊**，见「已知局限」。

### 部署（仅本地手动）

线上地址 [dod.goodpoint.top](https://dod.goodpoint.top) **只接受维护者本机发起的部署**

```bash
scripts/deploy.sh              # 构建 → 推送 GitHub → 同步服务器 → 健康检查（失败自动回滚）
SKIP_GIT=1 scripts/deploy.sh   # 只同步服务器，不动 git
```

服务器侧架构与脚本见 `deploy/`（Dockerfile、Nginx 配置）与 `scripts/server-deploy.sh`（原子切换 + 自动回滚）。服务器拉不动 Docker Hub，Dockerfile 基于本机已有 alpine 基础镜像构建，勿改回 `FROM nginx:...`。

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8787;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_connect_timeout 3s;
    proxy_read_timeout 10s;
}
```

## 已知局限 / 下一步

**画面与内容**

- 无真实扫描资产与动作捕捉；角色与武器仍是手工程序化几何，近景细节有限。
- 无全局光照/SSR/真实软阴影；接触阴影为半分辨率 SSAO，光照为单方向光 + IBL + 少量点光。
- 无动画状态机资源、无配音/配乐；无网络多人（排行榜只是单人成绩榜）。
- 敌人寻路是 **0.8 m 栅格 A\* + 局部转向**，不是带连接多边形的 navmesh；窄门、斜坡和贴墙仍靠 2D 碰撞推挤，个别地形会擦墙。
- 性能预算面向桌面独显/Apple Silicon；低端设备请切画质（SETTINGS 或暂停菜单内 LOW/MED/HIGH/ULTRA）。

**Sprint D 新增系统的边界**

- **排行榜不是反作弊。** ticket/HMAC、数值一致性、限流只能挡脚本乱刷与明显造假；改客户端内存后提交一组「自洽的假数字」仍会入榜。真正防护需要服务端权威模拟或回放，本项目没有。
- 服务端是**单进程 + 单 JSON 文件**，不支持多实例；每模式只保留 Top 50，跌出后查不到个人最佳；`X-Client-Id` 可伪造，不是账号体系，也没有跨设备同步。
- 呼号只存在本机 `localStorage`，没有账号/登录/找回：换设备或清缓存即换身份；改名不会回溯已入榜的旧记录。要真正跨设备，需要账号体系与服务端身份绑定（未实现）。
- 榜单是异步快照：断网时显示 `CACHE` / `LOCAL` 与上次同步时间，离线成绩进 outbox 等待补交；页面不会因为服务端不可达而卡住或空白。
- 拾取物不会自动重生；掉落武器**不可拾取、不供弹、不参与碰撞**（落地只做边界夹取）。10 个拾取 + 8 把掉落最坏约 +62 主 pass draw call（实测 10 个补给箱 +50 calls），所以有硬上限与 25 秒回收。
- 每日挑战按**本地日期**生成，改系统时间可以重刷；进度只存在本机浏览器。
- 炮火覆盖不做真实弹道与建筑遮挡：炮弹从高空垂直落下，屋檐边缘可能穿模；非屋顶区的高处结构不会被识别为落点。
- **AI v3 的边界**：敌方 VO 是 10 条系统 TTS 占位 MP3（降调+电台处理，非真人录音，可同名替换）；玩家只有破片手雷，没有闪光/烟幕可用，也不能回掷；破门只有北楼一扇门，重开 OP09 不会重置门状态；烟幕是球体视线遮挡 + 程序化精灵，不是体积流体；敌人不会被闪光致盲（只有玩家受影响，玩家也没有闪光）；不会主动打掉你的掩体；听觉只有“位置 + 误差”；垂直视野仍用 2D 碰撞体近似；掩体是离散点 + 碰撞面（但判定已改成 3D）；D1–D5 的数值未经真人长时间试玩校准；敌人不会闪避、不会因为玩家重复露头而调整、不会拆你的掩体；难度档之间仍是同一套状态机的倍率差异。
- **Season 3 的边界**：三个新区是同一套程序化材质/box 拼装的延伸，细节密度仍低于主街；工业区偏“空旷方块”，水面没有独立材质；三区没有新增点光源，night 天气整体偏暗。地图放大后 A* 默认预算提高到 60k 节点，极端跨区寻路有 CPU 成本。
- **LAN 的边界**：host 权威、客户端移动/射击被信任，改客户端可以作弊；无账号/密码/断线续局；co-op 4 人房 / versus 8 人房；JSON 20 Hz、无 delta/压缩，16 KB 单帧上限；客户端手雷由 host 权威模拟（出手即上报，爆炸与伤害在 host 结算并广播），敌方投掷物在 LAN 中关闭（客户端没有预警 HUD）；host 迁移不迁移战局；支持合作生存与阵营对抗，不支持战役/排行榜。
- **OP11–14 的 VO**：无线电仍是文字（无新录音），四场新过场是静默字幕巡游；只有结局沿用既有 TTS 台词。
- **Sprint N 仍未做的**：敌人没有合批/骨骼蒙皮（远处仍保留整副 rig，只关阴影与小网格）；没有自研 TAA；材质细节没有升级（仍是程序化 canvas，只是渲染预算重排）；没有"自适应难度"与难度选择器（分层按波次固定推进，玩家不能手动选档）。
