## 2. 结构诊断

### 三幕不成立，五幕成立

| 幕 | 关卡 | 功能 | 状态 |
|---|---|---|---|
| 一 · 断线 | OP01–OP04 | 世界失守，你是最后还在推进的人 | ✅ 成立。OP01 过场"整条防线只剩你还在推进"是全篇最好的动机内核 |
| 二 · 追猎 | OP05–OP07 | 哈桑 → 替身，第一次发现敌人用替身 | ✅ 成立，**但 OP05→OP07 三关里只有 OP07 有信息增量** |
| 三 · 封锁与入侵 | OP08–OP09 | 夺门 → 北楼 → 卡里姆 | ⚠️ 成立，但 OP08 与 OP06 目标重复（H4） |
| 四 · 余波与转移 | OP10–OP12 | （本该是）代价与追击 | ❌ **断链的一幕**：OP10 的结局片把幕间封死，OP11/12 又重新开门 |
| 五 · 终局 | OP13–OP14 | 港区 → 萨利姆 → 登船 | ⚠️ 萨利姆零铺垫（H8），OP13 读起来像又一个清场关 |

**为什么三幕读不通**：OP10 的完整结局（视频 + 过场 + "下一座城更大"）让玩家以为通关了，OP14 又来一次"结束"。于是"打完→再打一遍"的结构被玩家读成了三幕里的"第三幕是重复"。

### 实际中点：**OP07**

理由：
1. 全篇最大的信息反转在 OP07（替身），它本该是中点；
2. 卡里姆从 OP04 的 debrief（"最后一站，南院车场——他们的指挥官在那里"）就开始铺垫，OP07 是这条悬念的第一次兑现；
3. DISPATCH 的"指挥官车队已过北门"是线的转折。

**但 OP07 现在没有中点感**，因为它的 debrief 是一句**地理信息**（"真指挥官已进北楼"），不是一次**意义翻转**。要把它做成中点，只需一次认知升级：从"指挥官在北楼"升级为"指挥官**要你去北楼**"——这正好接得上档案里那句"不要拦截。让他到北楼来"（H11 的档案立刻从矛盾变成反转）。

### 泄气关（按严重度）

1. **OP10 余烬（最严重）** — 1 波清场 + 撤离，是全篇战斗量最小的一关（第 1/14 的量），却承载了唯一的完整结局过场。玩家的高潮预期在 OP09 卡里姆之后被立刻泄掉，又在 OP11 重新拉起。**节奏与叙事先泄一次。**
2. **OP02 市场（次之）** — 防守 45 s，是全篇最短的防守关（OP06/OP12 都 60 s），且是第二关、玩家刚学会移动射击；剧情上"抢补给"零代价。典型教学关的泄气。
3. **OP13 港区（轻微）** — 本该是"逼近终局"的倒数第二关，却因为对萨利姆零信息而读起来像又一个清场关。

（OP04 撤离也是低谷，但它是功能性刹车——时间推进到蓝调时刻，可接受。）

## 3. 玩家动机：分段审

| 段落 | "我必须去"的理由 | 判定 |
|---|---|---|
| OP01–OP04 | 全是"VEGA 让你去"（清街→拿补给→打通讯车→撤离）。**没有一句属于玩家自己** | ❌ 动机借来的。但 OP01 过场的"整条防线只剩你还在推进"其实是最好的动机内核——**一次都没被回扣** |
| OP05–OP09 | "指挥官在北边"是具体、可追踪、有终点的目标；每一关 debrief 都在推进一步（通行令 → 被拦下 → 是替身 → 进北楼 → 结束） | ✅ **全篇动机最强的段落，应该被复制** |
| OP10 | "指挥官倒了，这一区暂时安全" | ❌ 反向：这句话在劝玩家**别**再打 |
| OP11–OP14 | 动机句（"车队把货转进了老城""港区是他们的最后一站"）存在但被静音吞掉（H9）；剩下的是任务简报而不是玩家的理由 | ❌ 断裂。加上 OP10 已经给过一次结局，玩家心理是"我都通关了为什么还在打" |

**修法（零新增结构）**：把灰狼的动机从"上级命令"改成"**只有他能到**"。OP05 之后让 VEGA 明确一次"能走到北楼的只有你"；OP11 开头明确"卡里姆死了，**货还在**"。两句话就能把 OP01–OP04 和 OP11–OP14 的动机债还掉。

## 4. 反派威胁感：分量与血量倒挂

| Boss | 出现 | HP / 体型 | 阶段机制 | 台词 | 剧情分量 |
|---|---|---|---|---|---|
| 哈桑（副官） | OP05 | 560 / 1.16× | 盾卫 + 减伤 0.5 → 50% 冲锋 1.45× | 2 条（登场 + 一句） | 中。但"到死没开口"是**文档刻意强调**的限制，在 TTS 无限量下是自选的最贵约束 |
| 替身 | OP07 | **560 / 1.16×（默认值，`main.js:4268/4270`）** | **无 bossPhases（与哈桑机制完全相同）** | **0 条** | 高（作为反转装置）。**但机制上它就是第二个哈桑** |
| 卡里姆（主反派） | OP09 | 760 / 1.22× | 70%/40% 两次 relocate + 增援 | **1 条**（`karim_1`），**无阵亡台词** | **最高**，却只有一句话，死时无声 |
| 萨利姆 | OP14 | 900 / 1.2× | 60% 炮击（用玩家连杀系统打玩家）+ 30% 盾卫 | 0 条 | **最低**（零铺垫），血量最高 |

**递进是否成立**：机制上成立（阶段设计逐级加码），**叙事上不成立**——因为卡里姆只有一句"你进了我的楼，就别想再出去"，萨利姆一句都没有。

**三个低成本修复点**：
- `karim_2.mp3` **已录好但从未被引用**（`voice.js:72`）→ 给卡里姆一条阵亡/承认台词（承认"诱饵"计划），把 `codex.js:33` 那张手写命令在声音里收口；
- `moth_3.mp3` 已录未用 → 可作 M 的第一次露头；
- 替身：让 HUD 上的 Boss 名在击杀后**延迟 2 秒**才改成"指挥官替身"——一次纯 UI 时序改动，零资产成本，却能把反转的爽点顶到最高。

## 5. 节奏

### 模式排列（实测 `story.js`）

`OP01 生存3 / OP02 防守45 / OP03 生存3 / OP04 撤离2 / OP05 生存4 / OP06 防守60 / OP07 生存3 / OP08 撤离2 / OP09 生存3 / OP10 撤离1 / OP11 生存3 / OP12 防守60 / OP13 撤离3 / OP14 生存4`

- **OP01–OP08 是严格的 4 关一循环**（生存→防守→生存→撤离 ×2）。玩家在第 4 关就能预测第 5 关，8 关后完全可预测。**单调的根因不是"三种模式太少"，而是"排列是周期而非变奏"。**
- OP09–OP14 换了旋转（生存撤离生存防守撤离生存），节奏明显好转。**单调感集中在前 8 关。**
- Boss 间隔：OP05/OP07/OP09（每 2 关一个）→ OP10–OP13 **连续四关无 Boss**，只有 OP14。**中段空档过长。**

### 过场插入点判定

| 过场 | 触发点 | 时长 | 判定 |
|---|---|---|---|
| `op01_intro`（+ opening.mp4） | 第一关开始前 | 16 s + 10 s | ✅ **位置正确**（建立世界、零风险）。但 26 秒无操作偏长，可考虑把 opening.mp4 压到 6 s 版（`docs/cinematic-video.md` 里本来就写了 6 s 方案，实际文件是 10.08 s） |
| `hassan_intro` | OP05 Boss beat 触发时 | 8.6 s | ⚠️ **位置对（首次亮相前），但空间穿帮**（H5）。且过场期间 `G.state='cinema'`，波次/开火/受伤全暂停 → 玩家站桩 8.6 s 后 Boss 才在脚边刷出。**更严重的是：这场过场同时承担 Boss 战术教学（`boss_2`"正面打不穿，绕后，或者打头"），而它可被跳过——跳过的玩家会失去战术提示** |
| `boss_reveal` | OP07 Boss beat | 9.5 s | ⚠️ 同上，且坐标与 OP05 完全相同（H5），等于把南院布景搬到了北门 |
| `karim_intro` | OP09 Boss beat | 8.4 s | ✅ **内容是全篇最好的**（卡里姆终于开口、1.22× 重甲、室内）。但**位置应前移到"破门之后"**，让玩家在办公室里"看见他等着你"，而不是在别处 |
| `ending.mp4` + `finale` | **OP10 结算后**（不是 README 说的 OP09） | 10 s + 12 s | ⚠️ 位置在高潮之后 ✅，但它把 OP10 变成了伪终局（H6） |
| `ending2` | OP14 结算后 | 12 s | ✅ 位置正确；**但与 `finale` 说的是同一句话**（"暂时。下一座城更大。"） |
| `souk_intro` / `rail_intro` / `port_intro` / `finale2_intro` | OP11–OP14 第 1 波 | 9–10 s | ⚠️ 位置在关卡开始前 ✅，但全是 `silent:true` 静默字幕，且吞掉了各关的动机 radio（H9） |

**总结：所有过场都落在"玩法高潮之前或之后"，没有一处落在转折点上。** 而最值钱的三个转折（OP07 替身反转、OP10 假结局、OP13 萨利姆现身）**全部由结算面板/debrief 文本承担**——结算面板恰恰是玩家注意力最低、手已经要离开的时刻。**转折点应该由声音+字幕承担，而不是由结算面板承担。**

| 剧情节点 | 对应玩法 | 契合度 |

## 8. 结局收束

**现状**：OP10 = 结局 A（ending.mp4 + `finale`："暂时。下一座城更大。"）；OP14 = 结局 B（`ending2`："这座城结束了。" + "暂时。下一座城更大。"）。**两处结局说同一句话**——这不是收束，是同一句台词用了两遍。

**OP14 真正收束了什么**：杀掉第二个指挥官 ✓ / 货物没上船 ✓（但没说清）/ M 没有回答 ✗ / 灰狼的私人线没有收 ✗ / 北楼电台没有回答 ✗ / 卡里姆的诱饵计划没有被复盘 ✗

**OP14 还欠的（按优先级）**：

1. **一次复盘（最重要）**：卡里姆本想用诱饵引你去北楼——现在没有人对这件事说一句话。结局必须由 MOTH 或 VEGA 点破（"他知道我们会来"／"他没算到你会夺下北门"）。**这是唯一能让结局有重量的东西。**
2. **一件货的交代**："三箱文件"被截获了吗？给一个具体结果（"三箱文件在船上，我们带走了两箱"）比抽象的"结束了"有实感。
3. **只留一个钩子**：M **或** 北楼电台，不要两个都悬着。
4. **不要两个结局**：把 OP10 明确写成"假结局/中段"（推荐），或把 OP11–14 明确成独立战役（成本高，要新 UI 与新存档逻辑，对单人项目不划算）。

## 9. TTS 与 in-engine 过场的表达上限

**原则**：镜头里的角色只能做"姿态"（瞄准/行走/蹲/走位），不能做"表演"。凡是靠表情、微表情、眼神、拥抱、争吵传递的信息，必须迁移到 **声音 / 文字 / 物件 / 环境**。

| 剧情点 | 现在怎么做的 | 应改成什么载体 | 成本 |
|---|---|---|---|
| 哈桑"到死没开口" | 一具无台词的重甲尸体 | **物件叙事**：他身上那张通行令上，除了卡里姆的签名，还有哈桑自己的一行字 | 一张贴图 + 一行档案文本 |
| 卡里姆"把你当诱饵" | 藏在可漏捡的档案里 | **双确认**：档案设为 OP09 固定拾取（必得）+ 阵亡时他自己说（`karim_2` 已录） | 1 个拾取标记 + 1 条已有音频 |
| 萨利姆的登场 | 无 | **不做登场过场**：威胁来自 OP13 MOTH 的 UAV 侧影（静默巡游已有这个镜头语言），人到了 OP14 才有脸 | 0 |
| OP07 替身反转 | 藏在 debrief 结算面板 + 被"指挥官倒了"打断 | **反转是声音事件**：替身倒地 → VEGA 频道静默 1.5 s → 灰狼开口一句 | 1 条 TTS + 1 段静默 |
| 两个热源 / 无人应答的电台 | 两处钩子未回收 | **用结局字幕回答一个**（不是新过场） | 1 行文本 |
| 灰狼的动机 | 全篇无目标 | **一个私人锚点**：把 OP02 的补给 / OP05 的通行令变成"某个人在北楼等他"的由来 | 2 行文本 |

**通用叙事经验推测（针对你的技术约束）**：

- **TTS 的情绪上限是"语速/停顿/音量/音色"，不是"表演"。** 所以 Boss 的恐惧感应该来自 **"他什么时候开口"**——让 Boss 沉默整场，阵亡前 1 秒突然说一句话。这一招对 TTS 最友好、最省，而且效果远好于全程念台词。
- **静默是免费的。** `cinema.js` 里 `silent:true` 已经在用。关键反转处加 1.5–2 s 纯静默（只留环境音）+ 一行字幕，比补一条 TTS 的表现力更强。
- **字幕队列的上限是句子的节奏。** 你现在的台词水平是对的——"别在开阔地停留""绕后，或者打头""正面打不穿"。**不要为了"更完整"把句子写长**，那会同时降低 TTS 听感与字幕可读性。
- **不要用系统事件承载剧情反转。** "指挥官击毙 +1500"是玩家状态，"这是替身"是戏剧层，两者混用必然打架（H1/H2 就是这么错的）。**改法是把反转交给台词，系统层只报状态。**
- **敌人死亡是免费的镜头。** 三个 Boss 的尸体是你手里最值钱的静态资产：过场相机慢慢推过重甲尸体 + 一行字幕，比再加一个活人过场更便宜、更有分量。

## 11. 明确不做（长期，超出单人项目成本）

按你的约束，以下方向**不建议在 V1 做**，此处仅备案：

- 分支剧情 / 对话选项 —— 需要关卡状态机重写 + 结局分支，成本是整条线的数倍；
- 真人配音 / 动捕 / 面部表情 —— 与你的 in-engine 演员表演上限直接冲突（§9）；
- 真正的"卡里姆诱饵"多结局（玩家是否被利用）——建议只用**一条字幕 + 一个档案**暗示，不要做成机制。

## 12. 一句话给结论

**这条线不需要重写，它需要重新接线。** 玩家会记住的三个瞬间——OP01 的"只剩你还在推进"、OP07 的替身、OP14 的船——都已经写好了；现在挡在它们前面的，是系统文案、坐标、和一条播了两遍的结局视频。把这 5 处接上，OP01–OP14 就能读成一条完整的两幕进攻：*被当作诱饵放行 → 识破替身 → 反过来封死他的退路 → 拿走他的货*。
