# Deepseek of Duty — 画质与美术升级简报

## 目标与边界
- 延续现代战争、低太阳黄昏、磨损城市的既有方向，不更换题材。
- 修复暖雾同质化、阴影细节丢失、地面材质扁平和地标轮廓简陋。
- 保留现有地图尺寸、出生点、通路、碰撞、导航和联网玩法。
- 保留可玩的第一人称武器、士兵迷彩与 IK；不为“升级”而重建合格资产。
- 参考为 `shots/art-baseline/` 的四张实际游戏画面；本轮无新增外部资产。

## 视觉支柱
1. 暖色低太阳与中性偏冷阴影形成光色分工，而非全屏黄褐色滤镜。
2. 大表面依靠 albedo、normal、roughness 三层变化；结构轮廓依靠几何。
3. 前景材质清晰，中景地标明确，远景体块有屋顶设备与明度分层。
4. 集市是石材、水面与植物；铁路是钢构、枕木与信号；港口是箱体框架与门机。
5. 特效只辅助反馈，不用 bloom、雾或颗粒遮盖资产缺陷。

## 检查视图
- `street`：主街平视，检查冷暖、道路、武器和远景。
- `souk-plaza`：喷泉与棕榈，检查碗体厚度、水面和叶冠。
- `rail-yard`：站台下方，检查暗部、支柱、轨道和钢构。
- `port-yard`：集装箱场，检查箱体框架、门机和城市天际线。
- 对照输出：`shots/art-upgraded/`，保持与基准相同的 1600×900 机位。

## 材质与灯光
| 项目 | 升级方向 |
| --- | --- |
| 黄昏主光 | 保留低角度暖光，略降强度，防止亮部洗白 |
| 冷色补光 | 提高填充与环境可读性，阴影仍保持明确方向 |
| 雾与调色 | 降低黄雾、暗角和颗粒，恢复自然饱和度 |
| 沥青 | 修复粗糙度下限错误，保留油污和修补区的反射差异 |
| 石材 | 喷泉使用有厚度的环形剖面、檐口和分层基座 |
| 工业金属 | 保留 PBR 金属／锈蚀区分，增加框架、角件和支撑 |
| 水体 | 保留共享法线滚动，不新增透明叠层系统 |

## 制作路由
- 场景布局、建筑、集装箱、站台：继续 Three.js，便于保留碰撞、分区和静态合批。
- 喷泉、棕榈、门机细节：Three.js 参数化几何；复杂度不需要独立 DCC 工程。
- 天空、PMREM、雾、ACES、SSAO、战斗特效：继续 Three.js 既有系统。
- 角色与武器：继续现有 Three.js 几何、材质和动画，不做资产迁移。
- Blender 已确认可用；本轮没有必须依赖雕刻、布尔或烘焙的元素，因此不为了使用工具而新建资产管线。
- 不另建 Edit3D 工程：交付目标是对这个既有可玩项目进行增量升级。

## 性能预算
- 新增静态细节进入原有 souk／rail／port 分组，由 `mergeStatic()` 按材质合批。
- 不新增实时阴影灯，不新增逐帧对象分配，不引入 transmission 或大面积透明层。
- 远景不投射阴影；小型植物与装饰沿用既有无阴影策略。
- 优先增加轮廓信息而非随机撒 props；避免高密度重复零件。
- 验证实际页面 mesh／triangle／renderer.info；无硬件实机数据时不声称帧率提升。
