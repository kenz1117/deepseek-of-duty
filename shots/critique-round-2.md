## 2. 盲比（Round 2）

**协议与 R1 完全一致**：官方 MWII(2022) still → 双方同裁剪窗口（切掉底部 74px 去掉 `CALL OF DUTY MWII` logo/水印）→ 随机左右 → key 密封 → 先看图后开 key。

- 我的判断：**右边是 CoD**。
- 揭 key：`{"left":"DOD"}` → **判断正确**。
- 这次没有"1 秒就假"的感觉了：左（我方）在缩略图尺度上**读作一款正常游戏**，不再像 tech demo。我是在**看第二眼**时确认的 —— 因为左侧的枪太细、太暗、像几根细棍；路面平得像纸。
- **偏差声明**：这是"我方第一人称实机 vs CoD 官方电影化 still"。still 有浅景深、有美术摆拍、有后期调色；对 CoD 有利。**但即使把这个偏差扣掉，结论也不变** —— 因为在 1:1 尺度下（见 §4），我方仍有三处一眼可辨的破绽：
  1. 近景武器是**平涂材质**（无磨损、无 AO、无细节法线）；
  2. **全场景没有 AO**，所有物体与地面的接触处都是"贴上去"的；
  3. 枪口焰是**三团散景光斑**，不是火。
- 若是与 MWII 的**实机 HUD 截图**并排，识别会更快（因为实机里武器占画面更大、光更硬）。

## 4. 分项证据（R2）：哪些修好了，哪些没动

### 3.1 建筑与场景 — 4.0 → **6.0**（wide 6.5 / alley 4.5）

**修好了：**
- **窗洞有真厚度了。** `r2b-facadeR.png`（3×）能看见窗洞**内侧的暗面**（reveal）、**向外伸出的窗台**（顶面受光、底面暗）、窗框与十字中梃；玻璃后面有暖色室内。R1 是纯 2D 渐变 + 7px 描边。
- **天际线不再是灰板。** R1 灭点处那块无贴图灰方块消失了，换成一组有轮廓变化的楼群 + 一座**宣礼塔剪影**（`r2-hero-nohud.png` x≈720）。
- **屋顶有了女儿墙压顶**，右侧楼顶有可见的深色压顶带。
- **立面配件成体系**：空调外机、落水管、雨棚（带条纹帘边）、卷帘门（有真实波纹）、挂式招牌（带螺栓）、墙面壁灯。
- **街道纵深成立**：电线在两侧立面上有**锚点**并下垂，杆件投影落在路面（`r2b-sky.png` 右上）。

**没修 / 新问题：**
- **墙面贴图仍然"喷绘"。** `r2b-facadeR.png` 3× 下，墙面是柔和斑块 + 极低对比的竖向条纹，**没有骨料、没有灰缝、没有手抹痕**；同一块噪声在相邻墙面重复。
- **窗模块仍然高度重复**：右侧楼 4 层 × 5 列的窗，尺寸、中梃位置、窗台高度完全一致，只有"亮/暗"状态不同。
- **暗窗是纯黑空洞**：`r2b-facadeR.png` 左侧两扇窗是全黑矩形 + 一条白色反光条，没有玻璃反射、没有室内。
- **挂式招牌纹理像占位**：`r2b-facadeR.png` 中央那块招牌上是一个**十字形亮斑**（噪声的对称伪影），支撑钢丝向上去向不明。

### 3.2 材质与纹理 — 3.0 → **4.5**

**修好了：**
- **路面的"波点"没了。** R1 的规则白斑阵列消失，现在是连续的沥青 + 轮胎磨痕 + 细裂缝（`r2b-road.png`）。
- **人行道改成了独立板**（`level.js:213` 注释 "individual slabs so joints + level drift read"），接缝与高差读得出来。
- **木质道具成立**：alley 的木栅栏有板缝、有木纹、有厚度与倒角；木箱有木纹与棱边（`r2b-alleywall.png`）。
- 卷帘门、雨棚、沥青、混凝土的材质族区分开了。

**没修：**
- **1:1 下墙面依然是"喷绘纸板"**（alley 最明显）。
- **武器材质是最大短板**：见 3.5。
- **无 AO**（见 3.3），所以"材质对"也读不出体积。
- **UV 重复**：立面、招牌、木栅栏的纹理在相邻构件上可辨重复。

### 3.3 光照与阴影 — 3.5 → **5.0**

**修好了：**
- 死黑 20.3% → **10.3%**，≤13/255 31.8% → 22.4%。左楼背光面现在能读出窗、窗台、消防梯、木裙板。
- 太阳 disk 强度 18.0 → **6.5**（`sky.js`），过曝像素 3.24% → **0.67%**。
- **燃烧桶真的发光了**：`r2-hero-nohud.png` 里桶前方的卡车侧面、地面有暖色光池（R1 是零）。
- **枪口焰产生环境光**：枪口前路面 +32%，控制区 −0.4%（见 §1）。
- 电线杆/电线的投影落在路面，方向一致。

**没修：**
- **全局仍然没有 AO。** `grep -rn "SSAO\|GTAO\|aoMap"` → 无命中。表现为：雨棚根部无暗角、窗台与墙面交界无接触暗、木栅栏贴墙无缝隙暗部、混凝土护栏层与层之间只有几何缝没有遮挡暗。
- **viewmodel 不投影。** `src/player/viewmodel.js:62` `m.castShadow = false` —— 枪在路面上没有可辨的投影轮廓，这是"枪浮在世界之外"的最后一个来源。
- **色差（CA）仍开得过重**，在高对比边缘（窗框、电线、招牌）可见青/橙描边。R1 已指出，未改。
- **细几何走样**：电线是 1px 阶梯，无 TAA/FXAA；移动时会闪。

### 3.4 大气 / 雾 / 天空 — 3.0 → **6.0**（本轮最大提升）

**修好了：** 天空纯白 19.2% → **4.4%**；出现了真实的高光滚降、地平线暖色带、可见的云体与层次；远景楼群按距离衰减（`r2b-sky.png`），不再是"雾卡片 + 白洞"。日落在楼后形成柔和光晕，是目前最接近 3A 的成分。

**没修：** 天空顶部（y<80）仍是一段**平的灰褐色渐变**，几乎没有结构；无体积光/丁达尔；无近景浮尘。**距离 2% 目标还差 2.4pt。**

### 3.5 武器模型 — 2.0 → **5.5**（结构修好了，材质没有）

**修好了（结构性，全部通过）：**
- **占屏 30.2% 宽**（`_debug().coverage`），`coversCentre=false`，不再遮住画面重心。
- 枪朝向正确：向前右方，不再横穿画面。
- **ADS 红点 NDC [0,0]**，分划透过玻璃可见、居屏幕正中。
- 轮廓可辨认：消音器、护木（带 M-LOK 槽）、顶部导轨齿、光学镜、弹匣、枪托（带贴腮）、握把。
- 有抛壳、有枪口焰、有弹匣井。

**没修 / 新问题（本轮 Top 1 问题）：**
1. **材质是平涂。** `r2b-viewmodel.png`（2×）：机匣/护木是均匀的深蓝黑，**没有磨损、没有掉漆、没有指纹油污、没有螺丝/铭文/销钉**；棱边没有磨白。武器细节能量 3.47，只有立面（8.20）的 42%。
2. **消音器是一根光滑圆管**（`r2b-road.png` 3×）：纯色、平面着色、端面是一个平面圆片。它占近景面积很大，是最响的"占位感"来源。
3. **光学镜顶面是一块惨白色板**（`r2b-optic-hip.png` 6×）：黑色镜体上方一个**纯米白色硬边平面**，像未赋材质的面。
4. **腰射时红点画在镜体侧面**（`r2b-optic-hip.png` 6×）：分划板在**不透明的侧壁**上可见 —— 真实红点只能从镜筒后方透过玻璃看到。这是渲染/深度问题，不只是美术。
5. **ADS 下机身出现大面积米色"裸面"**（`r2b-ads-low.png` 3×）：贴腮/枪托是**纯米色 + 可见多边形棱面**（八角剖面），无贴图、无法线、无 AO；ADS 时它占据画面正中偏下，非常刺眼。

### 3.6 双手 — 1.5 → **4.5**

## 5. "能否冒充 CoD"—— R2 结论

**仍不能。但性质变了。**

- **R1**：结构错误（枪/手/天空/占比/对位）→ **1 秒内**判死。
- **R2**：结构基本正确，剩下的全是**工艺缺口** → **1–2 秒**可辨；需要看武器与接触阴影。

**如果只看缩略图/直播码率**：R2 的 hero/wide 有机会混过 1–2 秒。**如果并排静态对比 100% 裁切**：立刻可辨，证据是三项：近景武器平涂、全场景无 AO、枪口焰形态。

**要跨过"像 CoD"这条线，还差三件事**（按投入产出排序）：
1. 近景武器 + 手的一张 1k 材质 atlas（albedo/normal/rough/AO/磨损）；
2. 一个 AO pass（SSAO/GTAO）+ viewmodel 投影；
3. 枪口焰/曳光/烟的美术重做（形态 + 尺寸 + 贴枪口）。

## 6. 仍最伤真实感的 Top 3

### #1 近景武器与手的材质（含 3 个渲染/几何 bug）
- **证据**：`r2b-viewmodel.png` 2×、`r2b-road.png` 3×、`r2b-optic-hip.png` 6×、`r2b-ads-low.png` 3×。
  - 机匣/护木/**消音器圆管**纯平涂；武器细节能量 **3.47**（立面 8.20）；
  - 光学镜**顶面惨白硬边平面**；
  - **腰射时红点画在镜体侧面**（不透明面上可见分划）；
  - ADS 下**米色枪托裸面 + 可见多边形棱面**占画面正中偏下。
- **根因**：`src/player/viewmodel.js` + `src/player/gunmaterials.js` —— 几何已重建，但材质仍是"纯色 + 统一 roughness"；`reticle` 是 `renderOrder=5` 的独立平面（`viewmodel.js:280`），未做"仅透过玻璃可见"的遮挡/深度处理；枪托部件没有并入材质 atlas。
- **修复**：①一张 1k atlas（albedo/normal/rough/AO）+ 曲率磨白；②消音器/枪托并入 atlas 并加螺纹与铭文；③把 reticle 改为**镜筒内的玻璃面材质**（或 `depthTest` + 仅在视线穿过镜窗时绘制），腰射时不可见；④镜顶面给哑光 hood 材质，消掉白面。
- **收益**：这是 100% 裁切下最刺眼的一项；从 5.5 → 7.5 可期。

### #2 全场景无 AO + viewmodel 不投影
- **证据**：`grep "SSAO|GTAO|aoMap"` → 0 命中；`viewmodel.js:62 m.castShadow=false`。可见结果：雨棚根、窗台-墙交线、木栅栏贴墙处、混凝土层间、道具落地处**全部没有接触暗部**；路面无武器投影；死黑仍有 10.3%。
- **根因**：`src/core/postfx.js` 与 `src/core/engine.js` 的渲染管线没有 AO pass；viewmodel 被排除在 shadow pass 外（性能取舍，但代价太大）。
- **修复**：①在 bloom 之前加 SSAO/GTAO（半分辨率即可）；②viewmodel 只对 `receiver` 开 `castShadow`（或加一张枪底的 blob 贴片 decal）；③把死黑再压 3–4pt 到 ≤6%。
- **收益**：**性价比最高的一项**。AO 一上，所有道具立刻"落地"，光照从 5.0 → 6.5～7。

### #3 枪口焰 / 敌人武器
- **证据**：`r2b-flash.png` 3×（三团 ~250 px 散景碟 + 半透明烟球 + 六边形火花，偏离枪口 ~100 px，染橙 40% 画面）；`r2b-enemy.png` 4×（敌人步枪近乎白色/镀铬，是全画面最亮物体，且穿手而过）。
- **根因**：`src/fx/fx.js` 的 muzzle flash 由大尺寸 soft sprite 叠加而成，缺"星形/锥形"主体与短寿命；敌人武器复用了不合适的金属材质参数（metalness 过高 / env 强度过高）。
- **修复**：①焰体改为 2–3 层：核心亮星（小、硬、150–300 ms）+ 锥形焰（贴枪口、朝向枪管轴）+ 少量六边形火花（改圆形）；②烟改为有密度渐变的 billboard 链，体积下沉；③焰体锚点钳制在 muzzle world pos；④敌人武器换用与玩家一致的深色哑光材质族。
- **收益**：开火瞬间是 FPS 的"名场面"，这一项直接决定"像不像 3A"；从 4.0 → 7.0 可期。

## 8. Round 3 验收线（建议）

1. 天空 ≥242/255 **≤2%**；全帧 ≤5/255 **≤6%**。
2. 武器细节能量 **≥ 6.5**（接近立面）；腰射时**分划不可见**；ADS 无裸色棱面。
3. AO 开启后，雨棚根/窗台/道具落地处出现**可测暗部**（同一区域开启前后 Δluma ≥ 3）。
4. 枪口焰：直径 ≤ 60 px（1600 宽下）、锚定枪口误差 ≤ 8 px、寿命 ≥ 2 帧可见、**不出现散景圆盘状**。
5. 敌人武器亮度 ≤ 玩家武器亮度 × 1.2（当前是最亮物体）。

达标 4/5 以上，才有资格讨论"能不能混进 CoD 截图"。
